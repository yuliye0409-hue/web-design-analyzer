    DESIGN VOCABULARY

    常用原则与术语

    ↗
    Tooltip / 文字提示

    指向或聚焦某个元素时出现的简短说明。

    ⇄
    Responsive / 响应式

    布局随屏幕宽度变化，保持内容可读与操作可用。

    ⌁
    Accordion / 手风琴

    点击标题展开或收起对应内容的折叠列表。

    ◎
    Microinteraction / 微交互

    操作后的细小反馈；好的反馈说明系统已接收输入并展示结果。

    ≋
    视觉层级 / Visual Hierarchy

    通过字号、对比、位置和间距安排内容先后，让用户先看最重要的信息。

    ⊞
    渐进披露 / Progressive Disclosure

    先给核心内容，再逐步展开次要信息；减少首屏拥挤，但不隐藏关键决策信息。

    ↔
    命中区域 / Hit Target

    真实可点击范围应足够大，尤其要照顾触屏用户，不只看图标的视觉尺寸。

    WORKFLOW / GUIDE

    分析公开网页并保留证据。

    提交网址后，本地分析服务会在隔离的无登录浏览器中加载页面，采集桌面和手机截图、可见标题、区块、链接、图片与控件。网站本身不会收到你的登录凭据。

    当前分析由浏览器实测与本地规则生成，不调用云端大模型。自动化不会点击或提交目标站点控件；菜单反馈、滚动动画等隐藏状态需要你手动补充。无法访问或受到限制的网站会显示错误，不伪造分析结果。

    分析模块可以编辑、添加、排序。复制或导出的提示词会包含采集信息和验证边界。
